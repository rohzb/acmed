# acmed v0.3.4 Release Notes

## Summary

`v0.3.4` is a patch release that stabilizes CSR-mode issuance behavior across
CLI issuer backends.

## Fixed

- `acme_sh` issuer no longer requires/installs private-key output in CSR mode
  and now tolerates missing `fullchain.pem` by rebuilding it from available
  certificate artifacts.
- `certbot` issuer now honors client-provided CSR mode (`--csr`) and avoids
  key-path expectations in CSR flow, matching ACME finalize semantics.
- Added issuer wrapper regression coverage for certbot CSR mode.

## Compatibility

- Backward-compatible patch release.
- No ACME API schema changes.

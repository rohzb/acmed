# acmed v0.3.2 Release Notes

## Summary

`v0.3.2` is a patch release focused on making acme.sh installation/runtime
paths deterministic and robust for DNS API hook resolution.

## Fixed

- Moved acme.sh DNS hook handling to well-defined, ACMED-owned paths.
- Added explicit `--home` usage in acme.sh backend execution path.
- Updated Docker/entrypoint flow to ensure hooks are always present in runtime
  acme.sh home, including on fresh external data volumes.

## Compatibility

- Backward-compatible patch release.
- No ACME API or configuration contract changes.

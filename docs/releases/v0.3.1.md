# acmed v0.3.1 Release Notes

## Summary

`v0.3.1` is a patch release focused on operational troubleshooting clarity for
issuer failures.

## Fixed

- Added explicit worker-side error logging for issuance failures and issuer
  exceptions.
- Container logs now include order/issuer context plus artifact paths to
  `issuer-output.log` and `challenge-output.log` so failures can be diagnosed
  without database inspection.

## Compatibility

- Backward-compatible patch release.
- No ACME API or configuration contract changes.

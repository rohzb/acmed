# acmed v0.3.5 Release Notes

## Summary

`v0.3.5` is a patch release that fixes CSR-mode `acme_sh` artifact export for
non-ECDSA CSRs.

## Fixed

- `acme_sh` issuer no longer appends `--ecc` to `acme.sh --install-cert` in
  CSR (`--signcsr`) flows.
- This prevents RSA CSR issuance from failing with missing
  `certificate.pem`/`fullchain.pem` artifacts after successful ACME issuance.
- Added regression test coverage to lock CSR install behavior.

## Compatibility

- Backward-compatible patch release.
- No ACME API schema changes.

# acmed v0.2.8 Release Notes

Release date: 2026-05-21

## Highlights

- Improved ACME order polling behavior for clients waiting on issuer work.
- Added more operator-visible issuance diagnostics for slow or failed orders.

## Changes

- ACME order responses now include `Retry-After` while an order is in
  `processing` status.
- Finalize acceptance now emits an `order.finalize_requested` audit event.
- Successful issuance audit metadata now includes `issuance_duration_seconds`.
- Admin order listings now include latest issuance-attempt metadata, including
  result code and issuer stdout/stderr artifact paths.

## Operational Impact

- ACME clients receive an explicit polling hint while upstream issuance is
  still running.
- Operators can inspect admin order data and audit records to distinguish
  challenge completion from slower upstream issuer completion.

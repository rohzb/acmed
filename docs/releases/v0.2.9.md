# acmed v0.2.9 Release Notes

## Summary

`v0.2.9` is a patch release focused on deployment consistency for source-mode
compose workflows.

## Fixed

- Source-mode compose presets now pass profile-specific `ACMED_PLUGIN_DIRS`
  into core image builds so issuer addon tooling is installed when required.
- Source-mode compose presets now mount `deploy/config/config.issuers.example.yml`
  by default, aligning startup configuration with the currently implemented
  local issuer parser.
- Deploy bootstrap/docs defaults now point to the parser-compatible issuer
  config example and call out `config.remote.example.yml` as a non-default
  sketch.

## Compatibility

- Backward-compatible patch release.
- No ACME API contract changes.
- No breaking configuration key removals.

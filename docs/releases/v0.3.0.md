# acmed v0.3.0 Release Notes

## Summary

`v0.3.0` is a minor release that removes legacy plugin-addon and split deploy
paths, and standardizes on a lean direct-wrapper runtime model for `acme.sh`
and `certbot`.

## Changed

- Simplified Docker runtime to a single standard image that installs `acmed`,
  `acme.sh`, `certbot`, and certbot DNS plugins directly.
- Removed addon-specific Docker helper files and compose overlays used for
  old plugin-addon assembly flows.
- Simplified deployment compose presets to one source-build preset
  (`deploy/compose/compose.source.yaml`) and one prebuilt-image preset
  (`deploy/compose/compose.image.yaml`).
- Updated Docker/deploy docs and issuer config examples to match the direct
  wrapper runtime model.
- Removed unused issuer `capability_scope` configuration field and related
  parser/docs references.
- Removed stale deploy compatibility config
  (`deploy/config/config.remote.example.yml`).

## Compatibility

- This is a `MINOR` bump under pre-`1.0.0` SemVer rules due to configuration
  and deployment-surface simplification.
- ACME API contract remains unchanged.

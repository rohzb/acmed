# acmed v0.3.3 Release Notes

## Summary

`v0.3.3` is a patch release that fixes ACME finalize key consistency so issued
certificates match the client-provided private key.

## Fixed

- Persist validated finalize CSR as an order artifact.
- Worker issuance now forwards stored CSR to issuer backends.
- Prevents acme.sh from generating a replacement keypair for ACME finalized
  orders, eliminating certificate/private-key mismatch on clients.

## Compatibility

- Backward-compatible patch release.
- No ACME API schema changes.
